# みちしるべ：交通費精算ツール試作

最初に [HANDOFF.md](HANDOFF.md) を読んでください。目標は位置情報を中心とする移動記録と交通費計算です。現実装はカレンダーの候補整理部分で、位置履歴の読込は次の実装です。

## 起動

インストール不要。dist/index.htmlをブラウザーで開きます。架空データが入った確認版は examples/ダミー予定入り確認版.html です。

## 検証

Node.jsがある環境で、リポジトリのルートから実行します。

```text
node tests/test-core.cjs
node tests/test-ui.cjs
```

テストはブラウザーの見た目・端末の位置検知を検証するものではありません。

## データの扱い

examplesはすべて架空です。実際の位置履歴・住所・Googleの認証情報はリポジトリに追加しないでください。作業データはdata/private/等で管理します。既存Sitesの識別情報やGit設定はこの一式に含めていません。
